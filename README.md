# Paint Tool

Paint Toolは、ローカルで使うシンプルなペイントツールです。

v0.3.0以降は、描画向けの新しいデスクトップ版を配布します。旧版とはインストール先やプロジェクトの保存場所が異なるため、別アプリとして扱ってください。

## インストール方法

Paint ToolはGitHub Releasesからダウンロードします。
GitHubのアカウント登録やログインは不要です。

1. このページの右側、またはスマートフォン表示では下の方にある **Releases** を開く
2. 一番上に表示される最新リリースを開く
3. **Assets** を開く
4. Windows 向け zip を **Assets** からダウンロードする（当面の正式配布は Windows）
5. ダウンロードした zip を展開し、アプリを配置する（下記 Windows を参照）

注意: `Source code (zip)` や `Source code (tar.gz)` は開発者向けのソースコードです。通常のインストールには使いません。

## Windows

Windowsでは、最新リリースの **Assets** から `PaintTool-*-windows-x64.zip` をダウンロードしてください。

- zip を任意のフォルダに展開し、中の **Paint Tool** フォルダ内の `painttool_desktop.exe` を実行します
- インストーラー（`.msi` / `.exe`）は旧版向けです。v0.3.0 以降は zip が配布形式です
- `latest.json` や `update-qt.json` はアプリ内アップデート確認用のファイルなので、手動インストールには使いません

注意: コード署名をしていないため、Windows SmartScreenの警告が表示されることがあります。警告が表示された場合は、このアプリを信頼できる場合のみ **詳細情報** -> **実行** を選んでください。

## macOS

当面の正式配布は Windows です。Apple のコード署名・公証の準備が整うまで、macOS 向け zip はリリースに含まれないことがあります。

- Assets に `PaintTool-*-macos-arm64.zip` がある場合のみ、参考配布として試せます（Apple Silicon 向け）
- 署名・公証をしていないため、Gatekeeper で開けないことがあります
- Intel Mac 向け（`macos-x64`）は配布していません

## アップデート

- 起動時、またはメニューの「更新を確認...」から新しい版を確認できます
- リリースに zip と `update-qt.json` が公開されている場合、通知の **更新する** から zip を取得して入れ替え・再起動できます（ワンクリック更新）
- 自動更新用の配布ファイルがまだ無い、またはお使いの OS 向け URL が manifest に無い場合は、リリースページを開くので、**Assets** から zip をダウンロードして手動で入れ替えてください
- コード署名をしていないビルドでは、更新後も Windows SmartScreen の警告が出ることがあります。信頼できる場合のみ続行してください
- GitHub Releases から zip やインストーラーを手動で入れ替える方法も引き続き使えます
- `latest.json` は旧版向け、`update-qt.json` は新しいデスクトップ版向けです。どちらも手動インストール用のファイルではありません


## 旧版からの移行

- v0.3.0以降はネイティブ版です。旧版（〜v0.2.1）のアプリ内アップデートでは、この版には切り替わりません
- 旧版のプロジェクトやショートカット設定は自動では引き継がれません
- 旧プロジェクトが必要な場合は、当面は旧版アプリで開くか、バックアップを取ってから移行してください
